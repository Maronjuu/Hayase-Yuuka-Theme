# Yuuka Theme

A dark and expressive Visual Studio Code color theme
inspired by Yuuka from Blue Archive.

## Features

- Dark purple interface
- Expressive blue and periwinkle syntax palette
- Semantic highlighting
- Support for Java, C++, Python, JavaScript,
  TypeScript, HTML and CSS

## Doki Theme: wallpaper and status bar sticker

The repository includes two images you can use as a wallpaper and sticker with the Doki extension. 

To be able to set the sticker and the wallpaper along with this theme, you need to install Doki Theme from the extensions marketplace in vscode, and follow the intstructions of the Doki extensions to set custom wallpapers and stickers. Set the file path for your custom Yuuka wallpaper and sticker from the settings.

Recommended CSS settings for the sticker, when vscode is in full-screen:

z-index:100; background-position: 100% 94.5%; background-size: 380px
